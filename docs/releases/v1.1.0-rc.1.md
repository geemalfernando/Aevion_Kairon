# Kairon v1.1.0-rc.1

Release candidate for AWS staging with opt-in browser/native push, SES email and critical SNS SMS.

- Atomic notification outbox, SQS publisher/worker, encrypted contacts/devices, delivery leases/retries/expiry, SES bounce/complaint suppression and delivery logs.
- Current-user recipient checks, depot/outlet/vehicle response isolation, individual read status and account-scoped offline caches.
- HttpOnly browser refresh cookies with CSRF protection; revoked-session checks, logout, header-authenticated SSE, distributed TLS Redis rate limits, signed expiring proof URLs and security headers.
- ECS release and optional two-AZ network/Redis templates, least-privilege task roles, WAF, queue/DLQ and monitoring; deployment helper and checksummed source/infrastructure assets.

Validated locally: 112 server tests, typecheck, web build/lint, serverless bundle, dependency audits (zero known vulnerabilities at validation), isolated PostgreSQL transactional/RLS/session tests, Docker four-role walkthrough and HTTP security smoke. Capacitor projects synchronized; actual signed mobile builds and physical push delivery are not verified.

This is a prerelease. AWS is not deployed; credentials/account/domain and live provider configuration are required. Channels default off. SES production access, Sri Lanka SMS sender registration, Firebase/APNs configuration, alert subscription and database restore testing remain operator tasks. See DEPLOYMENT.md or docs/deployment.md in the source archive.

The existing static demonstration APK is not a binary built from this candidate. Retains Supabase; the entire RDS/CloudFront/independent-service blueprint is not implemented.
